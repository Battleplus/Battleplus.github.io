# Battleplus.github.io

Battleplus 的个人作品集主页，集中展示 GitHub 账号下的 14 个公开仓库，覆盖 AI 产品、强化学习、机器人仿真与量化研究。

## 项目展示

主页保留原有深色视觉、轨道首屏和深浅主题，在主体区域完整介绍 14 个公开项目。每个项目都包含项目定位、核心问题、技术方向、当前状态和 GitHub 入口；页面下方同时保留全部仓库的快速索引。

## 本地预览

这是一个无构建依赖的静态站点，直接打开 `index.html`，或在仓库目录启动任意静态文件服务器即可预览。

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件

- `index.html`：页面内容与语义结构
- `styles.css`：响应式布局、主题与动效
- `script.js`：主题切换和滚动进入动画
- `assets/avatar.png`：头像资源
