# Battleplus.github.io

Battleplus 的个人技术年鉴，完整介绍 GitHub 账号下的 14 个公开项目，覆盖 AI 产品、机器人强化学习、仿真、量化研究与数字体验。

## 设计结构

- 首屏：个人定位与 14 项目实践版图
- 研究地图：四条实践主线及其关系
- 项目年鉴：14 份同规格的正式项目档案
- 工作方法：从理解任务到验证交付
- 关于：个人方向与 GitHub 入口

页面会如实区分产品原型、研究基线、训练成果、实验框架和孵化项目，不把未完成仓库包装成成熟产品。

## 本地预览

这是一个无构建依赖的静态网站。可以直接打开 `index.html`，或在项目目录启动静态文件服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
