# Battleplus.github.io

Battleplus 的沉浸式个人作品集主页，集中展示 GitHub 账号下的 14 个公开项目，覆盖 AI 产品、强化学习、机器人仿真与量化研究。

## 项目展示

网站采用原创的沉浸式科技工作室视觉：交互式抽象主舞台、强对比大字、整屏项目场景和差异化项目配色。每个项目都包含项目定位、核心问题、方法、价值、当前状态和 GitHub 入口。

## 本地预览

这是一个无构建依赖的静态站点，直接打开 `index.html`，或在仓库目录启动任意静态文件服务器即可预览。

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件

- `index.html`：页面内容与语义结构
- `styles.css`：响应式布局、主题与动效
- `script.js`：主题切换和滚动进入动画
- `assets/avatar.png`：头像资源
